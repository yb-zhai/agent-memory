# Nebula Memory 仓库资源清单

> 用于抖音主页置顶，日常更新时直接改这份即可。
> 格式：每行一个资源名字，名字下一行是用途。

README.md
项目说明书，新人从这里开始，装法、用法、常见问题都在里面。

docs/快速上手.md
保姆级安装教程，小白照着做就能接上 AI。

docs/demo.gif
面板动图，展示记忆星云长什么样。

docs/screenshot.jpg
面板截图，一眼看清界面。

memory/
记忆核心引擎，负责存、找、忘，是整个项目的心脏。

memory/store.cjs
记忆的读写与打分，决定哪些记忆被想起、哪些被淡忘。

memory/recall.cjs
四路召回算法，从词、时间、关联、画像四个角度找回记忆。

memory/extract.cjs
从对话里挑出值得长期记住的内容，宁可少记也不错记。

mcp-server.mjs
AI 接入入口，让 Claude、Cursor 等工具能读写记忆。

server.json
官方 MCP 商店的登记卡，让别人能搜到这个项目。

panel.html
记忆星云可视化面板，把记忆画成可以看的星图。

server.js
本地服务，支撑面板和接口运行。

index.js / client.js
项目入口和调用接口，供其他程序接入。

lib/
辅助模块，包括多后端统一、密钥加密等。

scripts/
数据搬运脚本，把外部记忆镜像导入本地。

install.ps1 / install.cmd
一键安装脚本，把插件装进 DSH。

uninstall.ps1 / uninstall.cmd
一键卸载脚本。

config.example.json / .env.example
配置模板，告诉你能调哪些设置。

docs/发布链路与更新指南.md
发布说明书，记录怎么发新版、踩过哪些坑。

docs/后续方向待办.md
路线图，记录暂时不做、以后可能做的方向。

.github/workflows/publish-mcp.yml
自动发布脚本，每次更新自动同步到官方 MCP 商店。

package.json
版本号和身份信息，决定发布到哪个市场。

LICENSE
开源授权（MIT），随便用、随便改。
