# 快速上手（小白版）— 用 MCP 接入 Claude / Cursor / ChatGPT / Grok 等

> 这份指南是**给完全不懂技术的人**看的。跟着做，每一步都告诉你会看到什么、该做什么。全程**不需要写代码**。
>
> 下面用 **Claude Desktop** 做例子教你怎么配（它最标准）。你用的如果是 **Cursor / ChatGPT / Grok / Gemini / Windsurf**，步骤几乎一样——都只是在各自的「MCP 设置」里填 `command=node` + `args=你的 mcp-server.mjs 路径`。

---

## 一、先搞清楚：装完之后你会得到什么

装完之后，你的 Claude（或 Cursor）就有了**记忆**——它会记住你说过的话（比如"我喜欢喝冰美式"），下次对话自动想起来。

**全程不需要联网、不花钱、不上传你的数据**（记忆存在你自己的电脑里）。

---

## 二、你需要准备的东西（只有两个）

1. 一台 Windows 电脑；
2. 已经装好 **Claude Desktop** 或 **Cursor**。

> 没有的话，先装好 Claude Desktop（官网下载安装即可）。

---

## 三、第 1 步：检查有没有 Node.js

Node.js 是一个"运行环境"，我们这个记忆系统靠它跑。先看你的电脑装没装：

1. 按键盘 **`Win + R`**，输入 `cmd`，回车，打开一个黑色窗口；
2. 在黑窗口里输入（可以复制粘贴）：

   ```
   node --version
   ```

3. 回车。

**看结果**：

- 如果出现一串数字，比如 `v20.11.0` 或 `v22.x.x` → ✅ 你已经装了 Node，**跳到第四步**；
- 如果提示 `'node' 不是内部或外部命令` → ❌ 还没装，**看下面**。

### 还没装 Node 怎么办？

1. 打开浏览器，访问：`https://nodejs.org`；
2. 点绿色的 **LTS** 版本下载按钮（比如 "v22.x LTS"）；
3. 下载完双击安装，一路点 **Next → Next → 完成**（全部用默认选项）；
4. 装完后，**关掉再重新打开**那个黑色窗口，再输入 `node --version`，看到版本号就成功了。

---

## 四、第 2 步：把项目下载到电脑

1. 先装一个叫 Git 的工具（如果你电脑没有）：
   - 访问 `https://git-scm.com/download/win`，下载安装，一路 Next 即可；
2. 打开黑色窗口（`Win + R` → `cmd`），输入：

   ```
   git clone https://github.com/yb-zhai/agent-memory.git
   ```

3. 回车。等它跑完（会下载一堆文件，几十秒）。

**看结果**：窗口里出现 `agent-memory` 文件夹，说明下载成功。

> 记一下这个文件夹的位置——默认在你打开黑窗口的那个目录下。后面要用到它的**完整路径**。

---

## 五、第 3 步：找到项目文件夹的完整路径

1. 打开文件资源管理器，找到刚才下载的 `agent-memory` 文件夹；
2. 点进去，会看到里面有 `mcp-server.mjs`、`README.md` 等文件；
3. 点**地址栏**（顶部显示路径的那个白条），复制完整路径。

> 比如路径可能是：`C:\Users\你的用户名\agent-memory`

**把这个路径记下来，下一步要用。**

---

## 六、第 4 步：配置 Claude Desktop

1. 打开 Claude Desktop，点左下角 **设置（Settings）**；
2. 找到 **Developer / 开发者** 选项，点进去；
3. 找到 **Edit Config / 编辑配置**，会打开一个叫 `claude_desktop_config.json` 的文件；
4. 把下面的内容**整段复制**，粘贴进去（替换掉原有的 `mcpServers` 那一段）：

```json
{
  "mcpServers": {
    "agent-memory": {
      "command": "node",
      "args": ["C:\\你的路径\\agent-memory\\mcp-server.mjs"],
      "env": {
        "NEBULA_DATA_DIR": "C:\\你的路径\\memory-data"
      }
    }
  }
}
```

**重点：把两处 `C:\\你的路径` 换成你第五步复制的真实路径。**

> 注意：
> - 路径里的每个 `\` 都要写成 `\\`（两个反斜杠）；
> - `NEBULA_DATA_DIR` 是记忆存放的地方，可以设成任意文件夹（不存在会自动创建）。

5. 保存文件，**完全关闭 Claude Desktop，再重新打开**。

---

## 七、第 5 步：验证成功

重新打开 Claude Desktop 后：

1. 看左下角或设置里，应该出现一个叫 **agent-memory** 的 MCP 服务，状态是**已连接**（绿色对勾）；
2. 如果没有，点它旁边的"刷新"或"重连"按钮。

**看到 agent-memory 显示已连接，就成功了！**

---

## 八、第 6 步：装完之后怎么用（关键！触发句）

**MCP 是后台能力，装完不会弹任何界面**，AI 也不会自动知道"该用记忆"。你得**主动说触发句**，它才会调用工具。

这就是为什么很多人装完觉得"没用"——不是没装好，是没触发。

### 📝 存记忆

直接说：

> "**记住：xxx**"

例如："记住：我喜欢喝冰美式" "记住：我的 API 密钥是 sk-xxx，这个很重要"

AI 会调用 `remember` 工具写进本地库。

### 🔍 取记忆

新开一个对话（或隔几天后），问：

> "**我之前说过 xxx 吗？**" / "**你还记得 xxx 吗？**"

例如："我之前说过喜欢喝什么？"

AI 会调用 `recall` 工具从本地库找出相关记忆。

### 🛠 如果 AI 说"我不知道怎么用 / 我没这个工具"

直接告诉它：

> "你有 agent-memory 的 MCP 工具，里面有 remember / recall / stats / forget 四个，用它。"

AI 立刻就会了。**这不丢人——连 DSH 自己装完都一度忘了自己有这工具**，说一句提醒就好。

### ✅ 验证是否真的生效

1. 说"记住：我喜欢喝冰美式"；
2. **完全新开一个对话**；
3. 问"我喜欢喝什么？"；
4. 能答出"冰美式" → 记忆真的生效了 🎉

> 小提醒：AI 调用工具是在后台完成的，你可能看不到过程，只看到最终回答——这是正常的，不代表它没用。

## 常见问题（卡住了看这里）

| 问题 | 解决 |
|---|---|
| `node --version` 报错 | 回到第三步，先装 Node.js |
| `git clone` 报错 | 先装 Git（第四步第 1 小点） |
| Claude 里看不到 agent-memory | 检查第六步的路径写对没有（`\\` 双反斜杠）、有没有完全关闭重启 Claude |
| 路径找不对 | 在文件资源管理器地址栏点一下，就能复制完整路径 |

## 进阶（可选，不着急看）

- **换别的 AI 客户端**：Cursor / ChatGPT / Grok / Gemini 等，配置方式都一样——在它们的「MCP 设置」里加一个 server，填 `command=node`、`args=你的 mcp-server.mjs 完整路径`。核心就是"让那个 AI 能启动你的 mcp-server.mjs 这个文件"；
- **记关键信息**（API 密钥、称呼偏好），说"记住这个，很重要"即可，这类记忆会被**永久置顶**、不会被遗忘；
- 想看**可视化面板**（记忆星云），或者更多功能，见 [README](../README.md)。
